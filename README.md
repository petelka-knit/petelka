# Петелька — как выложить сайт

В этой папке готовый сайт. Ничего собирать и устанавливать не нужно: это обычные файлы.

| Файл | Зачем |
|---|---|
| `index.html` | весь сайт: редактор, раппорты, импорт картинки, режим вязания |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | значок и название, когда сайт добавляют на экран телефона |
| `sw.js` | чтобы сайт открывался без интернета |

## Проверить у себя

Просто откройте `index.html` двойным щелчком. Всё работает, кроме установки на телефон и режима без интернета: им нужен адрес с https, то есть уже выложенный сайт.

## Вариант 1. Netlify Drop (5 минут, проще всего)

1. Откройте app.netlify.com/drop и зарегистрируйтесь (можно через почту или GitHub).
2. Перетащите в окно браузера **всю папку** `petelka-site` (не zip, а распакованную папку).
3. Через несколько секунд Netlify покажет адрес вида `что-то-случайное.netlify.app`. Сайт уже работает.
4. В Site configuration → Change site name задайте понятное имя: `petelka.netlify.app`, если свободно.
5. Чтобы обновить сайт: Deploys → перетащите папку ещё раз.

## Вариант 2. GitHub Pages (удобно, если будете часто менять)

1. Зарегистрируйтесь на github.com, нажмите **New repository**, назовите, например, `petelka`, сделайте Public.
2. На странице репозитория: **Add file → Upload files**, перетащите все файлы из папки, нажмите **Commit changes**.
3. **Settings → Pages**: Source = Deploy from a branch, Branch = `main`, папка `/ (root)`, Save.
4. Через минуту сайт появится по адресу `https://ваш-логин.github.io/petelka/`.

## Свой домен (petelka.ru и т. п.)

1. Купите домен у регистратора (например, reg.ru или nic.ru).
2. В Netlify: Domain management → Add a domain. В GitHub: Settings → Pages → Custom domain.
3. Сервис покажет, какие DNS-записи добавить. Вставьте их в панели регистратора. Обновление занимает от нескольких минут до суток, https включится сам.

## Когда меняете сайт

Откройте `sw.js` и увеличьте номер в строке `const VERSION = 'petelka-v1'` (v2, v3…). Так у всех пользователей подтянется новая версия, а не останется старая из кэша.

## Что важно знать пользователям

- Схемы хранятся **в браузере** того устройства, где их нарисовали. Если почистить данные браузера, они пропадут. Поэтому в библиотеке есть «Резервная копия»: «Сохранить все» скачивает файл `.json`, «Загрузить» возвращает схемы, в том числе на другом устройстве.
- На телефоне сайт можно установить как приложение: в Safari «Поделиться → На экран „Домой“», в Chrome меню → «Установить приложение».
- Экспорт PDF при первом использовании скачивает небольшую библиотеку, нужен интернет. PNG и SVG работают и без него.

## Следующие шаги

- **Аккаунты и синхронизация между устройствами** — нужен сервер с базой данных. Если пользователи из России регистрируются по почте, их персональные данные по 152-ФЗ должны храниться в России, а на сайте нужна политика обработки данных. Детали стоит уточнить у юриста.
- **Главная страница, ссылки «поделиться схемой», оплата** — после этого.

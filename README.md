# Петелька

Сервис для вязальщиц: схемы жаккарда по клеточкам, раппорты и счётчик рядов.

**Открыть:** https://petelka-knit.github.io/petelka/

- Рисуйте схему по клеточкам своими цветами пряжи или сделайте её из картинки.
- Нарисуйте раппорт один раз, и он повторится по всей ширине полотна.
- В режиме «Вяжу» текущий ряд подсвечен, а направление и цвета петель подсказаны.
- Скачивайте схемы в PNG, PDF и SVG.
- **Крючок** (`crochet.html`): схемы в условных обозначениях рядами и по кругу, проверка схемы, расход пряжи, планировщик пледа из мотивов и карточка для соцсетей.

Схемы хранятся в вашем браузере. Чтобы не потерять их, время от времени нажимайте «Сохранить все в файл».
